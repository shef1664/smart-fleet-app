# smart-fleet-app

## Параметры загрузки и выдачи бетона

В форме рейса миксера водитель отдельно указывает марку/объём на заводе и у клиента, а также факт собственной догрузки. Расчёт суммы для клиента по-прежнему использует только клиентский объём. Проверка без отправки: `node --test tests/concrete-facts.test.mjs`.

Эта ветка не опубликована. Перед публикацией нужно сначала проверить и выложить совместимые изменения CRM и Pulsar-бота, сделать копию, сверить действующие заголовки листа «Рейсы» и провести один контролируемый тест с Директором. Само заполнение водителем не подтверждает заводскую ТН, закупочную цену или прибыль.
